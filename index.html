Team Win Probability Calculator

Quick Start
  • The report always uses the current Probability values.
  • Option 1: Type probabilities directly. For played games (UTSA, Utah State, Notre Dame, Auburn, Mississippi State, Florida, Arkansas) set 1.00 (win) or 0.00 (loss). Auburn, Mississippi State, Florida, and Arkansas are preset to 1.00.
  • Option 2: Enter point spreads (Spread = Opp − Texas A&M; negative favors A&M). Choose a model (Normal σ=13.5 or Logistic b=0.23), then click Update Probabilities from Spreads.
  • Option 3: Use ratings. Set Texas A&M Rating & HFA; fill opponent ratings (prefilled from Sagarin PREDICTOR where available). Click Update Spreads from Ratings → Update Probabilities from Spreads.
  • Calculate builds the distribution from the current probabilities. Clear Probabilities sets all to 0.50. Start Over restores defaults.

How to use this page

    
You have three ways to drive the final report. The report always uses the current “Probability” values for each game—everything else (spreads/ratings) is just a helper to fill those in.


    
Option 1 — Enter probabilities directly (fastest)

    
    
      
  1. Confirm the schedule and Home/Away/Neutral for each game.
    2. 
      
  2. For games already played (UTSA, Utah State, Notre Dame, Auburn, Mississippi State, Florida, Arkansas), set Probability to 1.00 for a win or 0.00 for a loss. (You don’t need spreads.)
    3. 
      
  3. For upcoming games, type your own Probability (0–1) based on your opinion, power ratings, injury news, etc.
    4. 
      
  4. Click Calculate to see the win-distribution and text report.
    5. 
    


    
Option 2 — Enter point spreads, then convert to probabilities

    
    
      
  1. In Spread → Probability Model, choose a model:
        
      
          
    • Normal (σ) (default σ ≈ 13.5 points is common for football margins), or
      • 
          
    • Logistic (b) (default 0.23).
      • 
        
    
      
    2. 
      
  2. For each upcoming game, enter the Spread using this sign convention:
    
        Spread = OpponentAdjusted − Texas A&M Adjusted
    
        Positive spread (+X) ⇒ opponent favored. Negative spread (−X) ⇒ Texas A&M favored.
    3. 
      
  3. (For already played games, leave the spread blank and set Probability to 1.00 or 0.00.)
    4. 
      
  4. Click Update Probabilities from Spreads to fill the Probability boxes via the chosen model.
    5. 
      
  5. Review/edit any probabilities you want, then click Calculate.
    6. 
    


    
Option 3 — Use ratings (e.g., Sagarin PREDICTOR) to create spreads, then probabilities

    
    
      
  1. In Global Ratings, enter (or use the prefilled):
        
      
          
    • Texas A&M Rating
      • 
          
    • Home Field Advantage (HFA)
      • 
        
    
        HFA is added to the home team only; neutral = no HFA.
      
    2. 
      
  2. For each opponent, enter its Team Rating. Several are prefilled from Sagarin PREDICTOR.
    3. 
      
  3. Ensure Home/Away/Neutral is correct for each game.
    4. 
      
  4. Click Update Spreads from Ratings.
    
        This computes:
    
        If Home: Texas A&M Adjusted = A&M Rating + HFA
    
        If Away: Opponent Adjusted = Opponent Rating + HFA
    
        If Neutral: no HFA added
    
        Then Spread = OpponentAdjusted − Texas A&M Adjusted.
      
    5. 
      
  5. Choose a model (Normal σ or Logistic b) and click Update Probabilities from Spreads.
    6. 
      
  6. Review/edit any probabilities, then click Calculate.
